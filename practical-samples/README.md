# 实操公开样题

本目录从 Private 完整实操题库中固定随机抽取 13 道非“2026 年仿真题”样题，用于公开展示题型和代码填空形式：

- Python：5 道
- Pandas：3 道
- 机器学习：1 道
- 系统运维：4 道

`questions.json` 只保留题干、填空占位符、学习说明和运行所需的公开信息，不包含原始完整代码、答案映射、源文件哈希或判分逻辑。`manifest.json` 记录抽样种子和题目编号，便于核对公开范围。

完整实操训练、答案校验、JupyterLab Notebook 和学习记录请使用 [Private 完整仓库](https://github.com/13306518212/ai-platform-study-system)。
