# 人工智能平台产品实现（初级）学习系统 · 实操训练与复测

项目标识：`ai-platform-study-system-showcase`

版本：V1.0（稳定版）

双击同目录的 `打开考试.command`，打开 Notebook 后运行唯一启动单元（Shift + Enter）。已打开的页面重新运行该单元即可加载新版，已有答案自动保存。

[本机考试入口](http://127.0.0.1:8889/lab/tree/practical/%E5%AE%9E%E6%93%8D%E5%A1%AB%E7%A9%BA%E6%A8%A1%E6%8B%9F%E8%80%83%E8%AF%95.ipynb)

## 四个入口

- **今日练习**：每组 15 题；每轮首场固定为 Python 5、Pandas 5、机器学习 2、运维 3，后续场次只抽取尚未覆盖题目并按剩余题量动态调整。本轮最后一组不足 15 题时，优先从错误题库补足，错误题不足再用已覆盖题兜底。题序、当前位置、草稿和完成情况保存到本机；同一天可继续未完成的一组。日期变化后会显示“开始今日练习”，自动创建新题组；上一组未完成的草稿会保留到专项练习。今日练习保持原版紧凑代码显示，不展开逐条学习注释。
- **专项练习**：每次启动重新排列，尽量错开相邻模块与主题；可按模块筛选。点击“更多”中的“开始新一轮专项练习”，可以只清空专项练习草稿并重新作答，历史提交、错题和复测记录仍然保留。
- **模拟考试**：30 分钟、每场最多 10 题。每轮首场保持 Python 3、数据处理 3、机器学习 2、系统操作 2；同一覆盖周期内跨场次无放回抽题，后续按剩余题目动态配平，最后不足 10 题时按剩余数量出题。顶部“更多”会显示模拟考试题库覆盖进度，覆盖完当前公开题库后自动开启下一轮。默认关闭补全，可在开考前打开；保留原题提示。模拟考试代码保持原版紧凑显示，不展开逐条学习注释。关闭页面不暂停，到时自动交卷；交卷后显示正确率、未填空数、耗时与各模块得分。这是训练配置，并非官方考试标准。
- **错题复习**：包含待复习和待巩固题。切换到这里不会清空草稿；点击“再试一次”开始新的独立填写。

## 简洁答题页

题目要求说明输入、目的和限制；“代码段讲解”默认折叠。填空框按关键词或表达式长度调整宽度；焦点所在行轻微高亮。编号提示保留，位于对应语句之后；长提示允许换行。

“检查答案”和“运行程序”共用一个反馈区，每次更新而不追加。先显示正确空数和错误方向；点击“查看解析与参考答案”才显示完整答案，并记录本轮已查看答案。错误空可直接修改，正确空也不会被锁住。要重新独立作答，使用“再试一次”；该按钮清空当前草稿，保留历史提交。

点击运行后，结果会直接显示在 JupyterLab 原生 Output 输出区（默认展开）；报错同时显示关键错误与完整输出。正常退出不等于逻辑正确，应结合判分和题目要求核对。模拟考试运行时不提前判分，交卷后统一解析。

## 首次记录与复测

每次检查或练习运行时，保存该次答案、判分、日期、是否查看答案、是否用过原生补全。相同答案连续点检查和运行不重复记次。

首次正确率按每题第一次提交的正确空数 / 总空数统计，后来订正不会覆盖第一次答案。辅助使用另行记录。“独立”指本轮首次提交且未查看答案，Tab 使用不直接认定为不会。原题提示和折叠讲解不算查看参考答案；仅提示或讲解的打开次数不统计。

- 答错或依赖答案完成且尚无独立通过记录时，标记“待复习”，通常安排隔天复测；“加入复习”可安排当天。
- 一次独立全对，标记“待巩固”，隔天再测。
- 不同日期两次独立全对，标记“已掌握”，移出错题复习，三天后可再次抽查。同一天重复全对不会直接升级。独立答对之后查看解析，不会抹去此前已取得的复测通过记录。

已检查或运行一次即计入本组完成；不要求立刻背出全部标准答案。错题继续进入复测计划。

顶部统计分为“今日”和“累计”两组：今日显示完成题数、提交次数、今日错题、到期复测和本轮覆盖；累计显示已练题数、首次正确率、独立答题率、待复习/巩固和已掌握题数。独立答题率只统计没有查看答案、没有使用 Tab 的首次提交，并同时显示已有独立记录的题数。“更多”中可查看模块覆盖、已掌握题数、提交及辅助使用统计、易错题和模拟历史，也可清空记录（二次确认，考试中不可清空）。

累计错误达到阈值的题目会显示“高频错误段落讲解”，按错误空号说明代码作用、判断依据和复习方法，不直接提前显示答案；展开参考答案后再核对具体写法。

## 旧进度兼容

沿用 `.python_fill_exam_progress_v2.json` 文件名，内部数据升级为版本 3。首次保存新版记录时，旧版文件备份为 `.python_fill_exam_progress_v2.json.before-v3.bak`。旧答案、错题和模拟历史保留；无法确定首次表现的旧题标为“未记录”，不推算首次正确率。无法解析的原文件不会被覆盖。

## 原生补全与运行

输入代码前缀后按 Tab，请求当前 Jupyter 内核的候选；↑↓ 选择、Tab / Enter 确认、Esc 关闭。空白输入框按 Tab 跳下一空。补全显示了候选会记录为使用过补全；不会从标准答案建立候选词库。格式符、数字、运算符等可能没有候选。前文语法不完整时应先补前文；此接口不含额外 LSP / AI 插件建议。

程序使用当前内核的 Python 环境，在独立临时目录执行，最多 30 秒。本机 POST 示例使用临时回环接口；两个附件 GET 示例仍需要联网。实时系统读数和线程顺序可能变化。

## 分享给其他人

推荐直接分享目录中的 `实操填空模拟考试.zip`。这个压缩包已经包含可运行所需的 Notebook、题库、界面模块、原生补全脚本、内核保护脚本和启动脚本；不需要把你的个人答题记录一起发出去。

对方在 macOS 上使用时：

1. 解压压缩包到一个普通文件夹，不要只在压缩包预览窗口中打开 Notebook。
2. 确认已安装 Python 3、JupyterLab 和 ipywidgets。题目运行还建议安装 `pandas`、`numpy`、`scikit-learn`、`requests`、`psutil`：

   ```bash
   python3 -m pip install jupyterlab ipywidgets pandas numpy scikit-learn requests psutil
   ```

3. 双击 `打开考试.command`。如果 macOS 阻止首次打开，可在“访达”中右键该文件，选择“打开”；若文件经过某些聊天软件传输后失去执行权限，在终端进入解压目录执行：

   ```bash
   chmod +x 打开考试.command
   ```

4. 浏览器打开本机地址后，运行 Notebook 中唯一的启动代码单元（Shift + Enter），即可进入答题界面。每个人的答题进度会保存在自己的目录中，互不影响。

Windows 或 Linux 用户可以在解压目录的终端运行：

```bash
python start_jupyter.py
```

然后访问终端显示的 `http://127.0.0.1:8889/...` 地址。若系统中的 Python 命令是 `python3`，将上面的命令替换为 `python3 start_jupyter.py`。启动脚本只监听本机，不提供局域网远程访问；需要多人同时使用时，每个人应在自己的电脑上单独启动一份。

分享前请不要把以下文件放进压缩包：`.python_fill_exam_progress_v2.json`（个人学习记录）、`.python_fill_exam_progress_v2.json.before-v3.bak`（旧记录备份）、`.jupyter-runtime/`（本机运行状态）和 `.ipynb_checkpoints/`（Jupyter 自动检查点）。当前交付压缩包已经排除了这些文件。

## 启动、重启与无响应处理

- 日常使用：双击 `打开考试.command`；若 JupyterLab 已在运行，脚本会复用 8889 端口。
- 页面显示但按钮没有反应：关闭旧的 JupyterLab 标签页，重新双击启动脚本，再重新打开 Notebook 并运行启动单元。新版在每次换题和重新渲染时会释放旧控件，减少重复运行造成的连接堆积。
- 仍无法启动：查看 `.jupyter-runtime/jupyter-exam.log` 的最后几行；最常见原因是 8889 端口被其他 Jupyter 进程占用。关闭占用该端口的 JupyterLab 后再启动。
- 不要同时运行多份 `打开考试.command`，否则多个窗口可能争用同一端口。

## 交付文件说明

- `实操填空模拟考试.ipynb`：极简启动单元，负责加载其余文件。
- `questions.json`：题库及答案校验信息。
- `notebook_app.py`：答题界面、判分、运行验证、学习记录和复测逻辑。
- `autocomplete.js`、`kernel_guard.js`：JupyterLab 原生候选补全和内核状态保护。
- `start_jupyter.py`、`打开考试.command`：本机免 token 启动入口。
- `使用说明.md`：本说明。

## 题库与维护

当前公开题库：13 题、60 空，包含 Python 5、Pandas 3、机器学习 1、系统运维 4。公开版使用完整判分、运行验证、学习记录和复测逻辑；完整题库版本另行维护。

Notebook 从同目录加载 `questions.json`、`notebook_app.py`、`autocomplete.js`、`kernel_guard.js`。启动脚本仅监听本机 8889，免密码和 token。开发资料位于 `.dev`；`build.py` 生成题库和极简 Notebook，`tasks.py` 保存逐题任务说明。`test_learning_v3.py` 验证迁移、续练、首次记录、间隔复测、辅助标记与考试边界；`verify.py` 验证原程序、判分及真实运行；`verify_kernel.py` 验证 Jupyter 内核。
